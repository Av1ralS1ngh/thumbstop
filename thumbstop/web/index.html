Promo finder for microdrama scripts

Thumbstop reads a season of timestamped screenplays and returns the 20 to 60 second promos that open on a hook, end on a cliffhanger and make sense to a stranger, each with a cut sheet an editor can use.

About $2.70 in model calls for a 50-episode show, and every re-run is free.

How a run works

Code does the counting and the cutting. The AI only points at numbered lines, so a cut point can't be made up.

  1. 1
    Read

    Every line of every script becomes a numbered beat with its start and end time.

    Code
  2. 2
    Mark

    Claude reads one episode at a time and points at the lines worth opening on and ending on.

    AI
  3. 3
    Cut

    Code tries every opening and ending pair against the rules: 20 to 60 s, a hook in 3 s, no line cut in half.

    Code
  4. 4
    Check

    A second model that has never seen the show watches each clip cold and says if a stranger would follow it.

    AI
  5. 5
    Rank

    Code ranks, keeps variety, flags ad-policy risk and picks what to post first.

    Code
