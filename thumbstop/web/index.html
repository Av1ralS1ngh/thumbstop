Promo finder for microdrama scripts

Find the promo hiding in every episode.

Give it a season of timestamped scripts. Bangerz finds the 20 to 60 second clips that open on a hook in the first 3 seconds, end on a cliffhanger and still make sense to a stranger, ranks them, and tells you which to post first.

  • 3 s hook, every time
  • 0 lines cut in half
  • 2 AI models, one checks the other
  • ~$2.70 for a 50-episode show

How it works

Five steps, and the AI never writes a timestamp

Code does the counting and cutting. The AI only points at numbered lines, so a cut point can't be made up.

  1. 1Read

    Every line of every script becomes a numbered beat with its timestamps.

    Code
  2. 2Mark

    Claude reads each episode and points at the lines worth opening on and ending on.

    AI
  3. 3Cut

    Every opening and ending pair is tried against the rules: 20 to 60 s, hook in 3 s, clean cuts.

    Code
  4. 4Check

    A different model watches each clip cold and says whether a stranger would follow it.

    AI
  5. 5Rank

    Best first, with variety, ad-policy status, cut sheets, an EDL and what to post first.

    Code

Uploaded scripts are processed in a temporary folder that is deleted when the run ends. Results stay in this server's memory for an hour so you can download them, and any API key is used for that one run and never stored.
